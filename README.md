# Vertex Engineering Services Limited — Website

Plain HTML, CSS and JavaScript. No build step. Free to host.

## Pages
index, about, services, industries, training, projects, hse-quality, careers, insights, contact, request-a-quote.

## Publish free (GitHub Pages)
1. Create a new GitHub repository (it can be separate from your other projects).
2. Upload everything inside this folder (not the folder itself) to the repository root.
3. Settings > Pages > Source: "Deploy from a branch" > main / root > Save.
4. Your site appears at https://YOUR-USERNAME.github.io/REPO-NAME/

Cloudflare Pages and Netlify also work: drag the folder in, no settings needed.

## Before you go live
- Contact details: open `contact.html` and replace the four [bracketed] lines.
- Forms: sign up free at formspree.io, create a form, then replace `YOUR_FORM_ID` in `contact.html` and `request-a-quote.html`. Until then the form shows a "not connected" message.
- Logo: the header uses a drawn VESL wordmark. Replace it with your transparent PNG/SVG logo when you have one.
- Slider images: already included as `assets/hero-1.jpg` to `hero-5.jpg` (recolored to the logo purple). To change one, replace the file with the same name.
- Only publish certifications, client names and project results you can verify.
