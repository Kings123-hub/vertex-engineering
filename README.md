# Vertex Engineering Services Limited — Website

Plain HTML, CSS and JavaScript. No build step. Hosted free on GitHub Pages.

Live site: https://kings123-hub.github.io/vertex-engineering/

## Pages
index, about, services, industries, training, projects, hse-quality, careers, insights, contact, request-a-quote, privacy-policy, terms-of-use, 404.

## Updating the site
1. Open the repo on github.com and tap **Add file > Upload files**.
2. Upload the changed files (files with the same name are replaced) and tap **Commit changes**.
3. Wait 1–2 minutes. GitHub Pages rebuilds automatically.

All files sit in one folder (no sub-folders).

## Settings
- Phone, WhatsApp, banner speed, floating buttons and form settings are at the top of `script.js` (CONFIG).
- Colours are at the top of `styles.css`.
- Project photos are `project-01.jpg` to `project-06.jpg`; captions are in `projects.html`.
- Banner images are `hero-1.jpg` to `hero-5.jpg`.

## Enquiry forms
With no form address set, the Contact and Quote forms send the enquiry to the company WhatsApp number.
To receive enquiries by email instead, create a free form at formspree.io and paste its address into `formEndpoint` in `script.js`.
